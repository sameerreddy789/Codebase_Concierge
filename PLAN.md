# Codebase Concierge — Hackathon Plan

## Track
AI Agents with Google AI Studio (Gemini models)

## Concept
Paste a public GitHub repo URL → AI ingests and understands the entire codebase → ask natural language questions, get answers with code references, architecture explanations, flow diagrams, and generated code diffs.

## Tech Stack (Finalized)
- **Frontend:** React + Vite + Tailwind + shadcn/ui + Framer Motion
- **Backend:** Python + FastAPI
- **AI:** Raw Gemini SDK (google-genai) — NO LangChain/LlamaIndex
- **Vector DB:** ChromaDB
- **Diagrams:** Mermaid.js (rendered client-side, generated by Gemini)
- **Storage:** Temp filesystem + JSON, no database
- **Auth:** None — public GitHub repos only

## Architecture (Simplified)
```
User pastes GitHub URL
      ↓
Backend clones repo → extracts structure → chunks code → indexes in ChromaDB
      ↓
User asks question in chat UI
      ↓
Backend retrieves relevant chunks + repo summary → sends to Gemini → streams response back
```

## Retrieval Pipeline (Hybrid Approach)
1. **Clone repo:** `git clone --depth 1` for speed.
2. **Scan structure:** Walk file tree, skip junk (node_modules, .git, etc.).
3. **Context Selection:**
   - **Small/Medium Repos (< 1MB code):** Send the ENTIRE codebase in the system prompt. Gemini 1.5's context window handles this easily and provides much better architectural understanding than RAG.
   - **Large Repos:** Use ChromaDB RAG. Chunk files (200 lines, 50 overlap).
4. **Metadata:** Store file path, line range, and *function/class names* (if detectable) to help Gemini cite sources.

## Multi-Agent Simulation (UI Focus)
Fake it through prompt structuring, but make it **visual**:
- **Analyst:** Uses a "terminal-style" font. Focused on file structure and dependencies.
- **Retriever:** Shows "searching..." animations with file names popping up.
- **Explainer:** Uses markdown, diagrams, and friendly tone.
- **UI Cue:** In the chat, show a small "Agent Thought Process" toggle that reveals the reasoning behind the agent's response.

## Hackathon "Wow" Factors (The Competitive Edge)
1. **"One-Click Onboarding":** A "Quick Start" guide generated by AI for any repo. "How do I run this?", "Where is the main logic?", "What are the environment variables?".
2. **Interactive Mermaid:** Make diagram nodes clickable. Clicking a node highlights the relevant file in the File Explorer.
3. **Voice-to-Query:** Add a simple mic icon for voice questions (Web Speech API is easy and impressive).
4. **"The Architect's Vision":** A 3D or visually striking graph of the codebase structure (even a simple one using a library like `react-force-graph` if time permits, otherwise stick to Mermaid).
5. **Live Diff Preview:** When Gemini suggests a change, show it in a side-by-side split view that looks like a PR.

## Success Rating & Strategic Advice
**Rating: 9/10**
The "AI for Developers" space is crowded, but a tool that *actually* understands architecture (not just code snippets) and generates diagrams is a high-value hackathon entry.

**Strategic Advice:**
- **Focus on the Demo:** Hackathon judges often spend only 2-3 minutes on your project. Ensure the first "Explain this repo" command is blazing fast (pre-cache it if possible).
- **The "Aha!" Moment:** The moment a user sees a complex auth flow rendered as a Mermaid diagram is your winning moment. Spend extra time on the "Mermaid Prompt Engineering" to ensure it doesn't hallucinate invalid syntax.
- **Gemini 1.5 Flash is your friend:** It's extremely fast. Use it for the chat, and use Pro for the initial "Deep Analysis" of the architecture.
